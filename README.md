# Vững Tay Lái

Ứng dụng web giúp ôn luyện lý thuyết giấy phép lái xe hạng B tại Việt Nam.

## Chạy cục bộ

```bash
npm install
npm run dev
```

## Kiểm tra và tạo bản GitHub Pages

```bash
npm run typecheck
npm run build:pages
```

Thư mục `out/` là bản xuất tĩnh dùng để kiểm tra trước khi triển khai. Mỗi lần đẩy nhánh `main`, workflow GitHub Actions sẽ tự động kiểm tra, build và triển khai lên GitHub Pages.

> Đây là ứng dụng học tập độc lập với bộ câu hỏi minh họa, không phải dịch vụ sát hạch chính thức.
